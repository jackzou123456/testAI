# 数据说明与练习路线
所有记录均为虚构教学数据，不对应真实人员。每行是一位模拟学员的一次报名，编号唯一。

- registrations.csv：程序输入，UTF-8 带 BOM，Excel 可识别中文。
- registrations.xlsx：同一份数据的 Excel 查看副本，附中文字段说明。初版程序读取 CSV，不读取 XLSX；修改 XLSX 不会自动更新 CSV。
- expected-summary.json：独立验算参考，仅供核对，不要让程序读取它来生成结果。

| 字段 | 含义与口径 |
|---|---|
| id / name | 唯一编号 / 虚构学员姓名 |
| department / city | 6 个部门 / 5 个城市 |
| registered_on | 报名日期，2026 年 4–6 月 |
| course | 4 门课程 |
| status | 已完成、学习中、未开始、已取消 |
| planned_hours | 课程计划时长 |
| hours | 实际学习时长；未开始和已取消为 0，学习中为部分时长 |
| score | 0–100 分；空白表示无成绩，不应当作 0 分 |
| feedback | 自由文本，允许空白；含逗号或引号时按标准 CSV 解析 |

## 可选尝试（不是必做顺序）
1. 上午第一版：运行初版，从以下方向或自己的想法中选一个小改动，按目标检查。
2. 完善：城市 + 部门 + 状态联合筛选；显示报名数、实际时长、有效报名数。
3. 图表：部门排名、按报名月份的趋势、课程报名分布；筛选时各区域联动。
4. 分析：有效报名完成率 = 已完成人数 / 排除已取消后的报名人数；零分母显示“暂无数据”。
5. 缺失值：平均成绩只统计有成绩的记录，同时展示有成绩人数；空反馈不计作有效反馈。
6. 导出：导出当前筛选明细，保留所有原始字段与 UTF-8 BOM；重新用 Excel 打开核对。

基准：总报名 180，实际时长 398 小时；已完成 117，学习中 31，未开始 15，已取消 17。
有效报名 163，完成率 117 / 163 ≈ 71.78%；有成绩 104 人。不要混用“全部报名”与“有效报名”的分母。
